# Piercing Angle & Depth Guide

A free reference for trained body piercers: how the entry angle and the tissue thickness decide the length and direction of a piercing channel, and why a tilted channel makes jewelry sit unevenly.

**Live tool:** https://poliinternational.com/piercing-angle-guide/

## Features

- **Angle visualizer:** drag the discs or use the slider; see the channel, which disc edge presses in and which lifts, and how much longer a tilted channel is.
- **Tissue thickness:** measured thickness with 0.1 mm steps, or typical values per placement; channel length = thickness / sin(angle).
- **Why this angle:** clearance and what goes wrong at a bad angle, placement by placement.
- **Angle error modes:** correct, too shallow, too steep and asymmetric, drawn on the same cross-section.
- **Paired piercing symmetry:** landmark guide and a left/right angle and height simulator.
- **Compare mode:** two placements side by side, printable.
- **Placement sheet:** one-page print or PDF for the piercing room.
- **Studio house standard:** preferred gauge, jewelry style and notes, saved in the browser.
- **Typical starting jewelry and healing time**, with links to the Jewelry Size Visualizer, Aftercare Schedule Generator, Healing Tracker and Piercing Migration Risk tools.
- Seven languages (English, French, German, Italian, Spanish, Portuguese, Dutch), millimetres or inches, light and dark themes, embeddable.

Everything runs in the browser. No account, no upload, no network calls.
